# Whatever Ventures website

A lightweight, dependency-free homepage for Whatever Ventures. Built as a single HTML file that can be deployed as a static Vercel project or served from any static host.

## Content and status

- Whatever Signal: publication initiative. External link points to the founder-provided Substack home.
- Product Viability Kill Test: free public tool. Does not promote or link to ungated paid fulfillment.
- SALT: omitted from public site entirely. The private concept and prototype are not advertised.
- Contact: the default email published in the Whatever Ventures Brand Style Guide v21.
- Company status: does not make unverified legal incorporation or customer-traction claims.

## Standards

Original website and copy. Brand colors from WV Brand Style Guide v21 (`#1C1C1C`, `#A67C52`, `#5A5A5A`, `#D9D6D2`, `#F3F0EC`, `#EEE9E4`). Serif headings and sans-serif body text. No reproduction of protected seal artwork. No paid scripts, tracking, cookies, third-party form processing or scheduled jobs.

## Local preview

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`.

## Limitations

The contact form opens the visitor's email application; no messages are collected on a server. Verify deliverability to the default contact email. External project links are separately maintained and may change. Domain configuration is not included.
